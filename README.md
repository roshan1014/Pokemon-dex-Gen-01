# Pikachu Assignment

## Overview

This is a simple HTML/CSS assignment featuring a Pikachu-themed Pokemon card layout. The page shows a split hero section with Pokemon details on the left and a Pikachu image on the right.

## Files

- `index.html` — the page structure and content
- `style.css` — the layout, colors, typography, and design styling
- `assets/` — image files used by the page

## How to open

1. Keep the project folder structure intact.
2. Open `index.html` in your web browser.

## Notes

- Image files are stored in the `assets/` folder.
- HTML now uses the correct asset paths so the images load properly.
- The layout uses a flex container for the `.hero` section.
- A Google font (`Poppins`) is loaded for text styling.

## Project features

- Responsive hero section layout
- Custom typography with Google Fonts
- Pikachu and Pokeball images
- Menu icon and slider-style dots on the right side
